# Word Division: Basic Rules and Compound Structure

**Source:** ALA-LC Romanization Table: Japanese (2022), §§6.1–6.4  
**Phase:** Phase 1 — Skill rules  
**Purpose:** Determine basic word boundaries for nouns, pronouns, compounds, and adjacent compound expressions before applying the more specialized prefix, suffix, loan-word, and proper-name rules.

> **Unofficial restatement.** This file is an unofficial, operational summary of the ALA-LC Romanization Table: Japanese (2022). It is not the official table; the source document always takes precedence. See NOTICE.md at the repository root.

> Word division is not equivalent to morphological tokenization. ALA-LC treats lexicalized compounds, modifiers, reading changes, and established phrases according to specific cataloging rules.

## 1. General word principle (§6.1)

Romanized Japanese uses spaces between words even though Japanese script normally uses little spacing.

The general rule is:

- **Write words separately.**
- When the boundary is doubtful, apply the more specific rules in §6.
- Add a variant when appropriate.

Sections 6.2–6.7 primarily cover nouns, pronouns, compounds, and foreign words. §6.8 covers other parts of speech.

---

## 2. Compound words: write as one word (§6.2.1)

Write established compound words as single words.

### Examples

`wareware`, `teashi`, `wagahai`, `kirisame`, `mukashibanashi`, `mizusakazuki`, `iyagarase`, `ukiyoe`, `okurigana`, `ronsō`, `kokusei`, `kazoku`, `kokumin`

A semantically important example is:

- 誰か → `dareka` when it means **somebody**.
- Compare §6.8.4, where interrogative 誰 + particle か is `dare ka`.

### Decision point

The same surface sequence may be one lexical unit in one context and multiple words in another.

---

## 3. Compounds containing medial `の` (§6.2.2)

Treat commonly used compounds containing medial `の` as one word when they are established lexical items, typically found in major dictionaries.

### Examples written as one word

| Japanese | Romanization |
|---|---|
| 茶の間 | `chanoma` |
| 茶の湯 | `chanoyu` |
| 世の中 | `yononaka` |
| 日の出 | `hinode` |
| 男の子 | `otokonoko` |
| 草の根 | `kusanone` |
| きのこ | `kinoko` |
| たけのこ | `takenoko` |
| 虎の巻 | `toranomaki` |
| 女童 | `menowarawa` |

### Examples written separately

- 先の戦 → `saki no ikusa`
- くだんのはは → `Kudan no haha`

### Context-dependent example

- ヤマノイモ → `yamanoimo` when it is the established Japanese name of *Dioscorea japonica*.
- 山の芋 → `yama no imo` when it means potatoes/yams from the mountains.

### Decision point

Dictionary lexicalization and sentence meaning may be necessary. A simple rule such as “remove spaces around の” is not valid.

---

## 4. On'yomi single-character modifiers (§6.2.3)

Write a compound as one word when an added single-character modifier is read in on'yomi.

### Examples

- 業思想 → `gōshisō`
- 核戦争 → `kakusensō`
- 核家族 → `kakukazoku`
- 寮生活 → `ryōseikatsu`

---

## 5. Kana or kun'yomi modifiers: write separately (§6.3.1)

Write separately a modifier consisting of kana or a character read in kun'yomi.

### Examples

| Japanese | Romanization |
|---|---|
| わが息子 | `waga musuko` |
| 我国 / わが国 | `waga kuni` |
| 我が子 | `waga ko` |
| この国 | `kono kuni` |
| あの町 | `ano machi` |
| 女絵かき | `onna ekaki` |
| ゲイ作家 | `gei sakka` |
| 味自慢 | `aji jiman` |
| ペット自慢 | `petto jiman` |
| 琴合奏 | `koto gassō` |
| ピアノ合奏 | `piano gassō` |
| 水資源 | `mizu shigen` |
| 米騒動 | `kome sōdō` |
| 男相手 | `otoko aite` |

### Decision point

The Skill must know whether the modifier is functioning with an on'yomi or kun'yomi reading, not merely that it is written in kanji.

---

## 6. Bracketed or quoted words (§6.3.2)

Separate a bracketed, quoted, or parenthesized character/word/phrase from the surrounding word with a space.

### Examples

- 「仁」思想 → `"jin" shisō`
- 「核」論争 → `"kaku" ronsō`
- 「わたし」改革 → `"watashi" kaikaku`

See also the punctuation rules in §§4.2–4.3.

---

## 7. Adjacent compound words (§6.4)

Write two or more adjacent compound words **separately**.

### Examples

| Japanese | Romanization |
|---|---|
| 六朝時代 | `Rikuchō jidai` |
| 国民主義 | `kokumin shugi` |
| 東洋学会 | `Tōyō Gakkai` |
| 日本国政事典 | `Nihon kokusei jiten` |
| 耳鼻咽喉科 | `jibi inkōka` |
| 学校図書館法 | `Gakkō toshokanhō` |
| 国分寺資料調査報告書 | `Kokubunji shiryō chōsa hōkokusho` |
| 兄弟姉妹達 | `kyōdai shimaitachi` |

### Decision point

A morphological analyzer may identify many smaller units. ALA-LC requires deciding which units form lexical compounds and which adjacent compounds remain separate.

---

## 8. Reading changes between joined compounds (§6.4.1)

When joined compound words undergo a phonetic reading change because of their combination, hyphenate the joined compounds.

### Examples

- 女中奉公 → `jochū-bōkō`
- 文芸読本 → `bungei-dokuhon`
- 株式会社 → `kabushiki-gaisha`
- 交流試合 → `kōryū-jiai`
- 夫婦喧嘩 → `fūfu-genka`
- 南部相撲 → `Nanbu-zumō`

### Decision point

The Skill must distinguish a reading change caused by compounding from a lexical form that is simply established as one word.

---

## 9. Single characters in succession (§6.4.1.1)

### 9.1 On'yomi succession (§6.4.1.1.1)

Write successive single characters read in on'yomi as one word.

Examples include:

- 都道府県 → `todōfuken`
- 市区町村 → `shikuchōson`
- 市町村 → `shichōson`
- 士農工商 → `shinōkōshō`
- 衣食住 → `ishokujū`
- 春夏秋冬 → `shunkashūtō`
- 花鳥風月 → `kachōfūgetsu`
- 冠婚葬祭 → `kankonsōsai`

### 9.2 Kun'yomi succession (§6.4.1.1.2)

Write successive single characters read in kun'yomi separately.

- 春夏秋冬 → `haru natsu aki fuyu`
- 父母 → `chichi haha` (compare on'yomi `fubo`)
- 兄妹 → `ani imōto`

### Decision point

The same written characters can produce different word division depending on the selected reading.

---

## 10. Successive single-character kana (§6.4.2)

Write successive single-character kana as one word.

- てにをは → `tenioha`
- こそあど → `kosoado`

But two ordinary multi-character kana words remain separate:

- あれこれ → `are kore`

---

## 11. Single-character modifiers with a common substantive (§6.4.3)

Write single-character modifiers that share a common substantive together as single words. When the source separates those modifiers with a middle dot, use a hyphen between them.

### Examples

| Japanese | Romanization |
|---|---|
| 小・中学校 | `shō-chūgakkō` |
| 小・中・高等学校 | `shō-chū-kōtō gakkō` |
| 小・中規模企業 | `shō-chūkibo kigyō` |
| 上・下水道 | `jō-gesuidō` |
| 農山漁村 | `nōsangyoson` |
| 中・近世 | `chū-kinsei` |
| 中近世 | `chūkinsei` |
| 農・工・鉱業 | `nō-kō-kōgyō` |
| 文・史・哲学 | `bun-shi-tetsugaku` |
| 行財政 | `gyōzaisei` |
| 乳幼児 | `nyūyōji` |

---

## 12. Established set phrases with reading changes (§6.4.4.1)

Write well-established set phrases with reading changes as single compound words.

### Examples

- 口下手 → `kuchibeta`
- 雪景色 → `yukigeshiki`
- 土砂降り → `doshaburi`
- 理屈通り → `rikutsudōri`
- 大和魂 → `Yamato-damashii`

The last example also reflects a proper-name boundary and hyphenation.

---

## 13. `会社` in corporate names (§6.4.4.2)

When `会社` occurs in the name of a corporation, always write it as **`Kaisha`**, ignoring a phonetic reading change that might otherwise occur.

### Examples

- 日産自動車株式会社 → `Nissan Jidōsha Kabushiki Kaisha`
- 沖縄文化有限会社 → `Okinawa Bunka Yūgen Kaisha`
- 木内酒造合資会社 → `Kiuchi Shuzō Gōshi Kaisha`

This is an explicit exception to ordinary reading-change treatment.

---

## 14. Suggested Phase 1 decision procedure

```text
Identify the candidate lexical units from the reading/analyzer output.
↓
Is there a specific §6.2–6.4 rule for the structure?
├─ yes → apply it
└─ no → default to writing words separately
↓
If の is internal, ask whether the expression is an established lexical compound.
↓
If kanji modifiers are involved, determine on'yomi vs kun'yomi function.
↓
If compounds are joined, determine whether a reading change triggers hyphenation.
↓
Apply explicit exceptions such as corporate-name 会社 → Kaisha.
↓
If lexical status or semantic function remains unresolved, emit a judgment point.
```

## 15. Automation notes

### Likely automatable

- Direct handling of bracketed/quoted units.
- Explicitly listed structural exceptions.
- Many on'yomi/kun'yomi succession patterns when reading information is reliable.
- `会社 → Kaisha` when corporate-name context is already established.

### May require contextual or lexical judgment

- Compound word versus phrase.
- Lexicalized medial `の` compound versus ordinary `X no Y` phrase.
- `dareka` versus `dare ka`.
- Whether a reading change is caused by compounding and therefore calls for a hyphen.
- Whether a set phrase is sufficiently established to be written as one compound.

### Open questions for Phase 1

- How closely do UniDic token boundaries correspond to ALA-LC word boundaries in these sections?
- Can dictionary lemma/compound information reliably identify lexicalized `の` compounds?
- Which analyzer fields are needed to distinguish on'yomi and kun'yomi modifiers?
- Can reading-change hyphenation be derived from token-level underlying and surface readings?
- Should established set phrases be handled by a small lexicon before invoking AI judgment?
