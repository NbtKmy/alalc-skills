# Numerals

**Source:** ALA-LC Romanization Table: Japanese (2022), §7  
**Phase:** Phase 1 — Skill rules  
**Purpose:** Convert and romanize Arabic digits and East Asian numerals, including proper-name and common-noun exceptions, customary readings, counters, contractions, and punctuation used with numbers.

> **Unofficial restatement.** This file is an unofficial, operational summary of the ALA-LC Romanization Table: Japanese (2022). It is not the official table; the source document always takes precedence. See NOTICE.md at the repository root.

> In general, ALA-LC converts East Asian numerals to Arabic numerals for clarity, but §7 contains substantial exceptions. When doubt remains, the source calls for judgment and variants as appropriate.

## 1. Arabic numerals (§7.1.1)

Keep Arabic digits as digits.

Write the ordinal prefix `第` / `dai` separately from an Arabic numeral. Hyphenate a number when it is joined to a common substantive or counter.

### Examples

- １日３回 → `1-nichi 3-kai`
- ６台の車 → `6-dai no kuruma`
- ４次元 → `4-jigen`
- 第１次予選 → `dai 1-ji yosen`
- 3・11 を超えて → `3.11 o koete`
  - possible variant: `San'ichiichi o koete`

---

## 2. East Asian numerals normally converted to Arabic digits (§7.1.2)

As a general rule, convert East Asian numerals to Arabic numerals.

### Examples

| Japanese | Romanization |
|---|---|
| 第六十周年 | `dai 60-shūnen` |
| 昭和五八年度 | `Shōwa 58-nendo` |
| 第二百十回 | `dai 210-kai` |
| 平成七年 | `Heisei 7-nen` |
| 二十世紀 | `20-seiki` |
| 第三卷 中世 | `dai 3-kan Chūsei` |
| 第二編 | `dai 2-hen` |

The general conversion rule is overridden by the proper-name and common-noun rules below.

---

## 3. Proper names: do not always convert (§7.2.1)

When an East Asian numeral is integral to an established proper name or expression and replacing it with Arabic digits would not represent the established form, spell out the numeral using the customary reading.

### Examples

- 三郎 → `Saburō`
- 五十嵐 → `Igarashi`
- 四万十川 → `Shimantogawa`
- 第一勧業銀行 → `Daiichi Kangyō Ginkō`
- 九十九里浜 → `Kujūkurihama`
- 二十四の瞳 → `Nijūshi no hitomi`
- 千夜一夜物語 → `Sen'ya ichiya monogatari`
- 十二夜 → `Jūniya`
- 百人一首 → `Hyakunin isshu`
- 八日目の蝉 → `Yōkame no semi`
- 八月の六日間 → `Hachigatsu no muikakan`

The source explicitly notes that several of these are **not known by a corresponding Arabic-digit form**.

### When in doubt, provide a variant

- 二・二六事件 → `Niniroku Jiken`; possible variant `2.26 Jiken`
- 第二次世界大戦 → `Dainiji Sekai Taisen`; possible variant `Dai 2-ji Sekai Taisen`

### Decision point

Proper-name status and established usage can override the default numeric conversion.

---

## 4. Proper-name contexts where conversion is appropriate (§7.2.2)

Convert to Arabic numerals when the original number is readily convertible and substantial meaning is not lost.

This applies especially to ordinal numbers used for divisions or sections of corporate bodies or branches of the armed forces.

### Examples

- 八月度報告書 → `8-gatsudo hōkokusho`
- 陸軍第百十一師団 → `Rikugun Dai 111 Shidan`
- 第六次開拓團 → `Dai 6-ji Kaitakudan`
- 法務省民事局第三課 → `Hōmushō Minjikyoku Dai 3-ka`

### Decision point

The question is not simply whether the expression contains a proper name; it is whether numeric conversion preserves the established meaning/function.

---

## 5. Common nouns (§7.3)

When an East Asian numeral forms part of a common noun, spell it out using the customary reading rather than converting it to an Arabic digit.

### Examples

- 八百屋 → `yaoya`
- 五月人形 → `gogatsu ningyō`
- 百科事典 → `hyakka jiten`
- 五人組 → `goningumi`

This rule requires identifying lexicalized common nouns rather than treating every numeral character mathematically.

---

## 6. Preferred readings of basic East Asian numerals (§7.4.1)

When a numeral must be spelled out, the source gives the following preferred basic readings:

| Numeral | Reading |
|---|---|
| 一 | `ichi` |
| 二 | `ni` |
| 三 | `san` |
| 四 | `shi` |
| 五 | `go` |
| 六 | `roku` |
| 七 | `shichi` |
| 八 | `hachi` |
| 九 | `ku` |
| 十 | `jū` |
| 百 | `hyaku` |
| 千 | `sen` |
| 万 | `man` |
| 億 | `oku` |
| 兆 | `chō` |

These are defaults, not universal replacements. The source instructs the cataloger to consider context, reference sources, proper-name readings, larger-number behavior, and customary readings.

Examples noted by the source include:

- 九州 → `Kyūshū`
- 七転八起 → `shichiten hakki` **or** `nanakorobi yaoki`

## 7. Native readings with counters (§7.4.2)

Use customary native Japanese readings for forms such as `人`, `つ`, dates, and similar expressions.

### Examples

| Japanese | Romanization |
|---|---|
| 一人 / ひとり | `hitori` |
| 二人 / ふたり | `futari` |
| 一つ / ひとつ | `hitotsu` |
| 二つ / ふたつ | `futatsu` |
| 三つ / みっつ | `mittsu` |
| 四つ / よっつ | `yottsu` |
| 五つ / いつつ | `itsutsu` |
| 六つ / むっつ | `muttsu` |
| 七つ / ななつ | `nanatsu` |
| 八つ / やっつ | `yattsu` |
| 九つ / ここのつ | `kokonotsu` |
| 十 / とお | `tō` |
| 一日 | `tsuitachi` |
| 二日 | `futsuka` |
| 三日 | `mikka` |
| 四日 | `yokka` |
| 五日 | `itsuka` |
| 六日 | `muika` |
| 七日 | `nanoka` |
| 八日 | `yōka` |
| 九日 | `kokonoka` |
| 十日 | `tōka` |
| 二十歳 | `hatachi` |

### Decision point

These customary readings are lexical/morphological exceptions and should not be derived by simply concatenating the preferred readings of the individual numeral characters.

## 8. Contractions with numerals (§7.4.3)

When spelled-out numeral expressions undergo contraction, represent the contraction with a doubled consonant as shown by the established reading.

### Examples

- 一夫一妻 → `ippu issai`
- 八方美人 → `happō bijin`
- 十進法 → `jisshinhō`
- 十戒 → `Jikkai`
- 兵法三十六計 → `Heihō sanjūrokkei`
- 日本百景 → `Nihon hyakkei`

The source notes that contractions may occur:

- with `一`, `八`, `十` before k-, s-, t-, and p-series syllables; or
- with `六` and `百` before k- and p-series syllables.

This describes where contractions may occur; use the established reading rather than forcing contraction in every phonologically possible environment.

---

## 9. Large-value East Asian numerals (§7.4.4)

When a number must be spelled out, write it as one number expression, but separate hundreds, thousands, tens of thousands, etc. with hyphens for numbers over 100 according to the source rule.

The source example is:

- 百二十五年史編纂委員会 → `125-nenshi Hensan Iinkai`
- possible spelled-out variant: `Hyaku-nijūgonenshi Hensan Iinkai`

The preferred main form in this example still uses Arabic digits under the general conversion rule.

---

## 10. Ordinal prefix and counters in spelled-out forms (§7.4.5)

When numerals are spelled out, write the ordinal prefix `dai` and counters as part of the number they precede or follow, while keeping that whole number expression separate from the word it modifies.

### Examples

- 第三勢力 → `daisan seiryoku`
- 第二次大戦 → `Dainiji Taisen`

Compare §7.1.1, where `dai` is separate before an **Arabic digit**, as in `dai 1-ji yosen`.

---

## 11. Middle dot between numbers (§7.5.1)

Replace a middle dot between numbers with a period, with no following space, when appropriate.

### Examples

- ２０・５世紀の音楽 → `20.5-seiki no ongaku`
- ８・１５前後 : 戦争と私たち → `8.15 zengo : sensō to watakushitachi`

But when the number names a specific event that is spelled out as a word in romanization, ignore the middle dot and do not insert a space or other character:

- 二・二六事件 → `Niniroku Jiken`
- 五・一五事件 → `Goichigo Jiken`

### Decision point

The Skill must distinguish a numeric notation from a lexicalized event name.

---

## 12. Ranges (§7.5.2)

Replace a middle dot or Japanese tilde `～` with a hyphen when it marks a numeric/date range.

### Examples

- 3・4 次元 → `3-4-jigen`
- 大正十・十一年報告 → `Taishō 10-11-nen hōkoku`
- 昭和 40 年～昭和 60 年 → `Shōwa 40-nen-Shōwa 60-nen`

---

## 13. Suggested Phase 1 decision procedure

```text
Identify whether the numeral is already Arabic or is an East Asian numeral.
↓
If Arabic → preserve digits and apply counter/ordinal hyphenation rules.
If East Asian → default toward Arabic conversion.
↓
Before converting, check:
- established proper name?
- lexicalized common noun?
- customary native/counter/date reading?
- established contraction?
If yes → spell out using the appropriate established reading.
↓
If proper-name context still permits transparent numeric conversion without loss,
convert to Arabic digits.
↓
Apply §7.5 punctuation/range handling.
↓
If established-name status or customary reading remains uncertain,
emit a judgment point and consider a variant.
```

## 14. Automation notes

### Likely automatable

- Conversion of ordinary East Asian numeric values to Arabic digits.
- Arabic-digit + counter hyphenation after counter boundaries are known.
- A table of native readings for `人`, `つ`, dates, `二十歳`, and other explicit forms.
- Direct §7.5 punctuation conversion after event-name status is known.
- A lexicon/table for common contraction patterns and established numeric compounds.

### May require contextual or reference-source judgment

- Whether a number is integral to an established proper name.
- Whether Arabic conversion would cause substantial loss of meaning.
- Whether a numeral expression is a lexicalized common noun.
- Choosing among customary/proper-name readings not determined by the basic number table.
- Whether a dotted number sequence names a lexicalized historical event.

### Open questions for Phase 1

- Can numeric spans and counters be identified reliably from UniDic output before ALA-LC transformation?
- What evidence should qualify an expression as an established proper name that must keep a spelled-out numeral?
- Which native/counter/date forms should be hard-coded versus dictionary-driven?
- How should the system distinguish mathematical/numeric `3.11`-style notation from lexicalized event names such as `Niniroku Jiken`?
- Should automatically generated digit/spelled-out variants be limited to cases explicitly suggested by ALA-LC examples or allowed more broadly when uncertainty is recorded?
