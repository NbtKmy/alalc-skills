# Geographic Names

**Source:** ALA-LC Romanization Table: Japanese (2022), §6.10  
**Phase:** Phase 1 — Skill rules  
**Purpose:** Apply ALA-LC word division and hyphenation to Japanese and foreign geographic names, jurisdictions, streets, stations, harbors, geographic features, modifiers, and abbreviated forms.

> **Unofficial restatement.** This file is an unofficial, operational summary of the ALA-LC Romanization Table: Japanese (2022). It is not the official table; the source document always takes precedence. See NOTICE.md at the repository root.

> Reading selection for a geographic name may require §2.4.2.2 or external/entity-specific evidence. This file assumes that the relevant reading has already been selected and focuses on word division and hyphenation.

## 1. Jurisdictions and streets: generic terms (§6.10.1)

Hyphenate a generic geographic term when it forms part of the name of a jurisdiction or street.

### Examples

| Japanese | Romanization |
|---|---|
| 東京都 | `Tōkyō-to` |
| 千代田区 | `Chiyoda-ku` |
| 有楽町 | `Yūraku-chō` |
| 山口県 | `Yamaguchi-ken` |
| 横浜市 | `Yokohama-shi` |
| 小川町 | `Ogawa-machi` |
| 小笠原村 | `Ogasawara-mura` |
| 二条通り | `Nijō-dōri` |
| 北条郷 | `Hōjō-gō` |

For 京畿道 the source gives different readings according to historical context:

- contemporary materials → `Kyongi-dō`
- colonial-era materials → `Keiki-dō`

### Singular exception

Always write 北海道 as one word:

- 北海道 → `Hokkaidō`

Do not hyphenate it as though it were an ordinary `-dō` jurisdictional suffix.

---

## 2. Compound generic geographic terms (§6.10.2)

When the generic geographic element itself forms a compound, write that compound separately from the proper-name element.

### Examples

- 小笠原村長 → `Ogasawara sonchō`
- 小川町史 → `Ogawa chōshi`
- 千代田区立 → `Chiyoda Kuritsu`
- 横浜市政 → `Yokohama shisei`
- 東京都民 → `Tōkyō tomin`
- 東京都議会 → `Tōkyō Togikai`
- 山口県報 → `Yamaguchi kenpō`
- ソウル特別市 → `Souru Tokubetsushi`

### Decision point

A generic suffix such as `-shi` is hyphenated when it is itself part of the jurisdiction name, but a larger compound such as `shichō`, `shisei`, or `Tokubetsushi` is separated.

---

## 3. `国` / `koku` in country names (§6.10.3)

Write `koku` as part of the country name.

- 日本国 → `Nihonkoku`
- 満洲国 → `Manshūkoku`
- 韓国 → `Kankoku`

---

## 4. Place name + `の` + generic term (§6.10.4)

Write the generic term for a province, estate, village, etc. separately when it is preceded by `の` and a place name.

### Examples

- 武蔵国 / 武蔵の国 → `Musashi no Kuni`
- 新田荘 → `Nitta no Shō`
- 磐余邑 → `Iware no Mura`

The conventional reading may contain `no` even when the written Japanese does not explicitly show it.

---

## 5. Modifiers that are part of jurisdiction names (§6.10.5.1)

When a modifier forms an integral part of a jurisdiction name, write it together with the name as one word.

### Examples

- 東伊豆町 → `Higashiizu-chō`
- 上北山村 → `Kamikitayama-mura`
- 内モンゴル → `Uchimongoru`
- 北朝鮮 → `Kitachōsen`

---

## 6. Modifiers of place names (§6.10.5.2)

When a modifier is not integrated into the jurisdiction name but modifies a place name, write it separately.

### Examples

- 東南アジア → `Tōnan Ajia`
- 北アメリカ → `Kita Amerika`

But an established abbreviated form can behave differently:

- 北米 → `Hokubei` (§6.10.8)

### Decision point

The distinction is whether the modifier is part of the established name or is an external modifier of that name.

---

## 7. Compound place names (§6.10.5.3)

Write compound names that designate merged places or contain a larger place name as single words before the geographic suffix.

- 宇治山田市 → `Ujiyamada-shi`
- 会津若松市 → `Aizuwakamatsu-shi`

---

## 8. Stations and harbors (§6.10.6)

Hyphenate generic terms for stations and harbors when they follow place names.

### Examples

- 東京駅 → `Tōkyō-eki`
- 横浜港 → `Yokohama-kō`
- 品川宿 → `Shinagawa-juku`
- 新横浜駅 → `Shin Yokohama-eki`

If the generic term instead forms an on'yomi compound, write that compound separately.

- 東京駅長 → `Tōkyō ekichō`
- 横浜港湾 → `Yokohama kōwan`

### Decision point

The Skill must distinguish a geographic generic attached directly to the place name from a larger lexical compound beginning with the same character.

---

## 9. Geographic features (§6.10.7)

Write the generic term for a geographic feature as part of the geographic name.

### Examples

- 隅田川 → `Sumidagawa`
- 浅間山 → `Asamayama`
- 琵琶湖 → `Biwako`
- 信濃路 → `Shinanoji`
- サイパン島 → `Saipantō`
- 十勝沖 → `Tokachioki`

If the generic term instead forms an on'yomi compound, write it separately:

- 琵琶湖畔 → `Biwa kohan`
- 浅間山麓 → `Asama sanroku`

---

## 10. Abbreviated geographic/proper-name forms (§6.10.8)

In general, write words consisting of or containing abbreviated proper names as single words.

### Examples (§6.10.8.1)

- 濃尾平野 → `Nōbi Heiya`
- 加越能 → `Kaetsunō`
- 京浜工業地帯 → `Keihin Kōgyō Chitai`
- 名神高速道路 → `Meishin Kōsoku Dōro`
- 信越線 → `Shin'etsusen`
- 欧米人 → `Ōbeijin`
- 留欧学生 → `ryūō gakusei`
- 英詩文 → `Eishibun`
- 対日貿易 → `tainichi bōeki`
- 加州 → `Kashū`

Capitalization still depends on the grammatical and proper-name status of the whole expression.

---

## 11. Abbreviated names of countries or languages (§6.10.8.2)

Hyphenate a compound consisting of abbreviated names of countries or languages, **unless the compound is normally contracted**.

### Hyphenated examples

- 日露外交十年史 → `Nichi-Ro gaikō jūnenshi`
- 日英独医語小辞典 → `Nichi-Ei-Doku igo shōjiten`
- 鮮満叢書 → `Sen-Man sōsho`
- 和漢書 → `Wa-Kansho`
- 日蒙関係 → `Nichi-Mō kankei` when referring to Outer Mongolia

### Contracted examples written as one word

- 日華大辞典 → `Nikka daijiten`
- 日中関係 → `Nitchū kankei`
- 満蒙開拓 → `Manmō kaitaku` when `満蒙` refers to the contracted proper-name expression involving Inner Mongolia described by the source

### Decision point

The source distinguishes productive abbreviated combinations from established contractions. Lexical/historical knowledge can therefore affect hyphenation.

---

## 12. Suggested Phase 1 decision procedure

```text
Classify the geographic expression:
jurisdiction/street / station-harbor / feature / modifier / abbreviated form.
↓
For jurisdiction/street generic term → hyphenate, except Hokkaidō.
For compound generic term → separate.
For country-name koku → join.
For place + no + generic → separate as X no Generic.
For modifiers → decide integrated name vs external modifier.
For station/harbor → hyphenate direct generic; separate larger on'yomi compound.
For feature → join direct generic; separate larger on'yomi compound.
For abbreviations → usually one word; hyphenate country/language abbreviations
unless established contraction.
↓
If historical period, name integration, or contraction status is unresolved,
emit a judgment point.
```

## 13. Automation notes

### Likely automatable

- A table of jurisdiction/street generic suffixes and their hyphenated forms.
- The explicit `Hokkaidō` exception.
- Direct station/harbor and geographic-feature handling when entity boundaries are known.
- The `koku` country-name rule.
- Known established contractions stored in a lexicon.

### May require contextual or reference-source judgment

- Historical reading choice such as `Kyongi-dō` versus `Keiki-dō`.
- Whether a modifier is integrated into an official jurisdiction name.
- Whether a suffix-like element is a direct geographic generic or part of an on'yomi compound.
- Whether an abbreviated country/language expression is a normal contraction.

- Should official jurisdiction names and common abbreviations be maintained in a dedicated geographic lexicon?
- Can UniDic segmentation identify the direct-generic versus on'yomi-compound distinction reliably?
- How should historical-period evidence for geographic readings be represented in the observation record?
