# Notice

## Rule files (`skills/alalc-romanize/rules/`)

The files under `skills/alalc-romanize/rules/` are an **unofficial, operational restatement** (a paraphrase of the parts needed to run the skills) of:

> *ALA-LC Romanization Table: Japanese* (2022 version), approved by the Library of Congress and the American Library Association.
> https://www.loc.gov/catdir/cpso/roman.html

- They are not the official table and may contain mistakes or omissions. **The original table always takes precedence.** Check the original before cataloging.
- They are **not covered by the MIT license** of this repository. Copyright in the original table stays with its rights holders.
- If a rights holder asks for it, the rule files will be withdrawn (removed from the repository, including its history) and permission will be requested. The code does not depend on the text of the rule files, so the tools keep working without them.
